Sums up Thursday 19 November 2026's world news in one image: a newspaper front page. Lead story: Trump, Xi and Putin meet in Shenzhen for the first trilateral of sitting U.S., Russian and Chinese presidents, with an AI-generated editorial illustration of the summit skyline. Also on the page: GTA VI launches worldwide, Jeffries is nominated for Speaker, Cyclone Akvan nears India, and Voyager 1 reaches one light-day — plus a briefs strip (EU proposes a €45bn Ukraine loan, U.S.–Iran fire widens in the Gulf, Nvidia halts H-chip shipments to China, Gaza rains displace thousands). The program copies the bundled front page (`entry.png`) to `/output/entry.png`, so it is deterministic and offline: two runs write identical bytes.

## Run it

```sh
python3 main.py
```
